# Self-hosted fonts

Latin-subset WOFF2 files from Fontsource (npm `@fontsource-variable/*` 5.3.0,
`@fontsource/silkscreen` and `@fontsource/young-serif` 5.3.0): Fraunces, Cormorant Garamond, EB Garamond,
JetBrains Mono, Space Grotesk, Silkscreen, Young Serif. All are licensed under the
SIL Open Font License 1.1 (`OFL.txt`; each family's copyright is held by its
authors). Loaded with `next/font/local` so builds never fetch from Google Fonts.
